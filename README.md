# 💌 For Shreyaaa | Confession & Proposal Website

A romantic, interactive website built specially to express your feelings to **Shreyaaa**.

## ✨ Features
1. **Interactive 3D Envelope & Wax Seal**:
   - Realistic 3D flap opening animation.
   - Heart confetti burst and magical chime sound effect.
2. **Heartfelt Confession Letter**:
   - Gentle typewriter reveal animation with skip option.
   - Elegant typography with personal note for Shreyaaa.
3. **Reasons Why Shreyaaa is Unforgettable**:
   - Interactive glassmorphic cards highlighting her smile, kindness, laughter, and presence.
4. **Interactive Proposal Finale**:
   - **"YES! 🥰" Button**: Triggers full-screen fireworks, floating hearts, and celebration card.
   - **"No 🙈" Button**: Playful runaway button that flees whenever hovered or touched, growing the "YES" button larger each time with cute teasing lines.
5. **Plan Our First Date & Golden Ticket Generator**:
   - Choose a date activity and special day, then export a high-res PNG Golden Pass!
6. **Dreamy Ambient Music & Vinyl Player**:
   - Built-in romantic Web Audio API synthesizer with spinning vinyl widget.

---

## 🎨 How to Customize
Open `config.js` in any text editor to customize:
- `yourName`: Change your signature/name.
- `letterParagraphs`: Edit any sentences or add personal memories.
- `reasons`: Add specific shared jokes or moments.
